# ExamScannerAI

AI-powered exam paper scanner that extracts text, recognizes diagrams, and organizes questions into searchable study material for students.

## Features

- OCR text extraction
- Diagram recognition
- Smart question categorization
- Topic-wise organization
- Search functionality
- Markdown/PDF export

## Tech Stack

- Python
- FastAPI
- OpenCV
- Tesseract OCR
- AI APIs
- React (Frontend)

## Project Goal

To help students digitize and organize engineering exam papers efficiently using AI and computer vision.

## Planned Features

- Handwritten text recognition
- Mathematical equation detection
- Difficulty analysis
- Marks prediction
- Semantic search
